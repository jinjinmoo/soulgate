# Soulgate

A single-file HTML5 monster-hunting browser game. `index.html` plus the `sprites/`, `music/`, `ui/` and `sfx/` asset folders. No build step: Vercel serves it as a static site.

Music and sound credits: `music/CREDITS.txt`, `sfx/CREDITS.txt` (CC0).

## Deploys

Every push to `main` deploys to Vercel automatically (project `soulgate`).
